Tool Guides

Snippet Vault

Save code snippets with titles, languages, and tags. Supports 12+ languages with syntax highlighting.

  • Drag & drop the grip handle (⋮⋮) to reorder snippets
  • Multi-select checkboxes for bulk actions (delete, export, change language)
  • Search by title, tags, language, or code content
  • Export/Import your snippets as JSON files
  • Undo/Redo any action with Ctrl+Z / Ctrl+Shift+Z
Regex Forge

Test regex patterns with real-time match highlighting and capture groups.

  • Enter a pattern in the top field and see matches highlighted instantly
  • Flags: g (global), i (case-insensitive), m (multiline), s (dotAll), u (unicode), y (sticky)
  • View capture groups ($1, $2, etc.) for each match
  • Matches show position index in the source string
JSON Wizard

Format, minify, validate and colorize JSON data with syntax highlighting.

  • Format: Pretty-print with 2-space indentation
  • Minify: Remove all whitespace for compact output
  • Validate: Check if JSON is valid with detailed error messages
  • Real-time validation as you type
ColorCraft

Generate color palettes from images and explore color harmonies.

  • Upload an image or enter a URL to extract dominant colors
  • Adjust the color count slider (2-10 colors)
  • Pick colors with the color picker or hex input
  • Harmonies: Complementary, Analogous, Triadic, Tetradic
  • Click any palette color to copy its hex value
Markdown Editor

Write Markdown with live preview and export to HTML.

  • Split view: editor on left, live preview on right
  • Supports GFM (GitHub Flavored Markdown): tables, task lists, strikethrough
  • Export HTML: Download as a standalone HTML file
  • Copy HTML: Copy rendered HTML to clipboard
  • Fullscreen: Distraction-free editing mode

Tips

Theme modes: Click the theme button to cycle: Dark → Light → Auto (follows your OS setting).

Install as PWA: Use your browser's install button or the "Install as App" link on the landing page for offline access.

Privacy first: All data stays in your browser. No servers, no tracking, no cookies.

Zen mode: Press F11 to hide all UI elements and focus on your code.

Command palette: Press Ctrl+K anywhere to quickly navigate between tools.
